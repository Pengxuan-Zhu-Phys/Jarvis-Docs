# Example: SUSYRun2 (EWMSSM)

## YAML and Run

- YAML: [SUSYRun2_EWMSSM.yaml](SUSYRun2/SUSYRun2_EWMSSM.yaml)

```bash
jplot SUSYRun2_EWMSSM.yaml
```
Or using the following command to generate the plots without the gambit icon

```bash
jplot SUSYRun2_EWMSSM.yaml --print
```
